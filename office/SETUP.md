# ตั้งค่าเว็บหลังบ้านร้านชุติมา

เว็บใส่ Publishable key ที่ส่งมาแล้ว สิ่งที่ยังต้องทำคือสร้างบัญชีเข้าเว็บและติดตั้งตารางสินค้าใน Supabase

## 1. สร้างบัญชีเข้าเว็บ

เปิด Supabase โครงการ `dgvdwdmaxvtfnjiiixcm` ไปที่ **Authentication → Users → Add user → Create new user**

ใส่อีเมลเจ้าของร้าน ตั้งรหัสผ่านเอง และเลือกยืนยันอีเมลให้ผู้ใช้ (Auto Confirm User) บัญชีนี้เป็นบัญชีของแอป ซึ่งแยกจากบัญชีที่ใช้เข้า Supabase Dashboard

ไม่ต้องส่งรหัสผ่านกลับมาในแชต

## 2. สร้างตารางและสิทธิ์

เปิด **SQL Editor → New query** คัดลอกไฟล์ `setup-inventory.sql` ในโฟลเดอร์เดียวกับคู่มือนี้ แล้วกด Run เพียงครั้งเดียว

จากนั้นเปิด `grant-owner.sql` แก้อีเมลบรรทัดที่ระบุให้ตรงกับบัญชีที่สร้างในข้อ 1 แล้วรันไฟล์นี้ เพื่อให้บัญชีนั้นเข้าถึงข้อมูลของร้านได้

ตารางใหม่แยกจากระบบสถานะคิวซัก–อบเดิม และไม่ได้เปิดให้ผู้เยี่ยมชมทั่วไปอ่านหรือแก้ข้อมูลร้าน

## 3. เข้าเว็บ

กลับไปหน้าเว็บหลังบ้าน แล้วเข้าสู่ระบบด้วยอีเมลและรหัสผ่านที่สร้างไว้

หากขึ้น “รอข้อมูลจาก POS ครั้งแรก” หมายถึงบัญชีพร้อมแล้ว แต่ยังไม่มีข้อมูลสินค้าที่ส่งจากโปรแกรมร้าน

## 4. เชื่อม POS

ต้องใช้ POS รุ่นที่มีเมนู **ตั้งค่า → เชื่อมเว็บหลังบ้าน** และเปิดใช้งานการรับรายการจากเว็บก่อน รุ่น 0.14.0 เดิมยังไม่มีส่วนนี้

หลังเชื่อมต่อ โปรแกรมจะส่งข้อมูลสินค้า สต๊อก ผู้จำหน่าย และจัดซื้อมายังเว็บ รายการจากเว็บจะรอ POS บันทึกและส่งผลกลับมา หากปิดโปรแกรม ไม่มีอินเทอร์เน็ต หรือพนักงานเปิดฟอร์มค้างอยู่ จะยังแสดง “รอ POS บันทึก”

หากการตรวจนับถูกปฏิเสธเพราะยอดเปลี่ยน ให้กดอัปเดตข้อมูลแล้วนับใหม่ ไม่ต้องส่งรายการเดิมซ้ำหลายครั้ง
