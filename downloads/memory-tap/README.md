## เริ่มใช้งาน
1. ปิดตัวช่วยเดิม แล้วเปิดหน้าแอป ปิด “โหมดตรวจจับอย่างเดียว” และเปิด “วนซ้ำ”
2. กดข้อ 3 เปิดตัวช่วยและยืนยันแชร์หน้าจอ เข้า Roblox และเปิดมินิเกม
3. กด “กรอบ” ลากครอบตาราง 4×3
4. กด “ปุ่มเล่น” บนแถบลอย แล้วแตะกลางปุ่มเล่นสีเขียวในเกมเพื่อจำตำแหน่ง
5. ลากแถบลอยออกนอกตารางและปุ่มเล่น กด “เริ่มวน” ครั้งเดียว

แอปกดเล่น → อ่านไฟ → แตะคำตอบ → รอปุ่มพร้อม → เริ่มรอบใหม่ต่อเนื่อง
ถ้าจับไม่ครบหรือไม่เจอ จะล้างลำดับแล้วรอปุ่มเล่นกลับเป็นสีเขียวก่อนกดเล่นใหม่ ไม่กดรัวขณะที่ปุ่มเทา
ปุ่ม “หยุด” หยุดวน / “×” ปิดตัวช่วย การสลับออกจาก Roblox หรือหน้าจอเปลี่ยนจะหยุดวน

ส่งออก JSON พร้อมโน้ตปัญหาจากหน้าแอปเพื่อตรวจแก้ได้
