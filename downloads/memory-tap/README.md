# Memory Tap 0.3.0 — แก้การยกเลิกชุดไฟจากสีปุ่ม

[ดาวน์โหลด APK 0.3.0](Memory-Tap-0.3.0.apk?raw=true)

ติดตั้งทับรุ่นเดิมได้ ใช้แพ็กเกจและลายเซ็นเดิม

## เปลี่ยนหลักการควบคุม
- สีปุ่มไม่มีสิทธิ์ยกเลิกการจับใน WAIT_NEW/RECORDING
- เริ่มจับชุดจากไฟดวงแรกที่ยืนยันจริง
- หลังแตะครบ ฟังภาพต่อทันทีและกรองแสงตอบสนองจากช่องสุดท้าย
- เมื่ออ่านพลาดกลับ SEEKING ซึ่งยังรับภาพ/รับไฟได้เสมอ ไม่ล็อกรอปุ่มเล่น
- กด Play เฉพาะ SEEKING เมื่อตารางไม่มีไฟและปุ่มพร้อมต่อเนื่อง 1.5 วินาที
- เพิ่ม button_state พร้อมสัดส่วนเขียว/phase/เวลา และ first_flash เพื่อวิเคราะห์เครื่องจริง

## ใช้งาน
1. หยุดตัวช่วยเดิม ติดตั้ง APK ทับ เปิดวนซ้ำและปิดตรวจจับอย่างเดียว
2. เปิดตัวช่วยและยืนยันแชร์จอ เข้าเกม ตั้งกรอบตาราง 4×3 และพิกัดปุ่มเล่น
3. ลากแถบลอยออกนอกพื้นที่กด กดเริ่มวนครั้งเดียว
4. หยุด = หยุดวน; × = ปิดตัวช่วย ส่ง JSON จากหน้าแอปเพื่อตรวจผลได้
