## แก้ปัญหาจาก 0.2.0
เกมเปลี่ยนชุดไฟเองหลังตอบครบ รุ่นนี้กลับไปจับไฟชุดใหม่โดยตรง ไม่รอปุ่มเล่นและไม่กดเล่นซ้ำทุกชุด ใช้ปุ่มเล่นเฉพาะเริ่มเกมครั้งแรกหรือเริ่มใหม่หลังผิดพลาด ตัดเวลาหน่วงหลังแตะช่องสุดท้ายเพื่อกลับมาฟังไฟได้เร็วขึ้น

## ใช้งาน
1. ปิดโหมดตรวจจับอย่างเดียว เปิดวนซ้ำ แล้วเปิดตัวช่วย/แชร์หน้าจอ
2. ตั้งกรอบตาราง 4×3 และตำแหน่งปุ่มเล่นสำหรับเริ่มเกม/กู้คืน
3. ลากแถบลอยออกนอกพื้นที่กด แล้วกดเริ่มวนครั้งเดียว
4. แอปจำไฟ → แตะครบ → จับไฟชุดถัดไปต่อเองแม้ปุ่มเล่นยังเทา
5. กดหยุดเพื่อหยุดวน หรือ × เพื่อปิดตัวช่วย

ส่งออก JSON จากหน้าแอปเพื่อตรวจแก้ได้ เหตุการณ์ auto_next หมายถึงจับชุดใหม่โดยไม่แตะปุ่มเล่น
