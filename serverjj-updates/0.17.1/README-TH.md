# ตัวเชื่อมเว็บ SERVERJJ 0.17.1
ติดตั้งบน SERVERJJ เท่านั้น ใช้ POS รุ่นเดิมที่จับคู่แล้ว ไม่ต้องติดตั้ง POS ใหม่

รองรับ VAT รายเอกสาร (ไม่มี/รวม/แยก), ข้อมูลร้านและเอกสาร, แก้ใบสั่งซื้อ, แก้ไขและยกเลิกใบรับโดยเก็บประวัติ
สำรองฐานข้อมูลชุติมาก่อนอัปเดตอัตโนมัติ และคืนไฟล์บริการเดิมเมื่อเริ่มบริการใหม่ไม่สำเร็จ

ใบรับที่มีรายการขาย/รับ/คืนสินค้าภายหลังแล้วไม่ย้อนแก้ เพื่อรักษาต้นทุนย้อนหลัง ให้ใช้คืนสินค้าแทน
แก้ใบรับรอ POS ทุกเครื่องส่งยอดและพักสิทธิ์ขายสินค้าที่เกี่ยวข้องก่อน ไม่เรียกคืนสิทธิ์จาก POS ที่ออฟไลน์
เอกสารยกเลิกเก็บประวัติ เลขเอกสารเดิมไม่ถูกนำกลับมาใช้
ต้นทุนรับเข้ารวม VAT และค่าขนส่ง ส่วนลดคิดก่อน VAT; ค่าส่งใช้อัตราเดียวกับเอกสาร
