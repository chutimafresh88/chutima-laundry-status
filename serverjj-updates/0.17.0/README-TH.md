# อัปเดตเว็บและ SERVERJJ 0.17.0

เปิด Chutima-Server-Update-0.17.0.exe บน SERVERJJ แล้วกดอัปเดตหนึ่งครั้ง ตัวติดตั้งสำรองฐานข้อมูลชุติมาก่อนเปลี่ยนบริการ และคืนไฟล์บริการเดิมถ้าตรวจเปิดบริการไม่ผ่าน

หลังขึ้นว่าอัปเดตเรียบร้อย เปิดเว็บหลังบ้านและกดอัปเดต จะมีใบสั่งซื้อ รับบางส่วน รับตรงด้วยบาร์โค้ด รายงาน Excel และภาพรวมร้าน

หน้า “พนักงานและสิทธิ์” ให้เจ้าของร้านสร้างชื่อผู้ใช้และรหัสผ่านเอง ไม่ต้องใช้อีเมลพนักงาน เลือกสิทธิ์ผู้จัดการ ดูรายงาน หรือดูสต๊อก

ใช้ POS 0.16.1 ที่จับคู่ไว้ต่อได้ แยกการติดตั้งจาก SML และ PostgreSQL ของ SML

รายงานใช้ข้อมูลที่ SERVERJJ รับแล้ว เครื่องออฟไลน์อาจยังมีรายการรอส่ง ต้นทุนรายงานขายใช้ต้นทุนตอนขาย ถ้าไม่มีต้นทุนย้อนหลังจะแสดงว่าง
